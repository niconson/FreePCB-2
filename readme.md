FreePCB v2.4
--------------

В этой версии добавлена поддержка экспорта файлов в OpenSCAD — The Programmers Solid 3D CAD Modeller.
Проект собран на VS22. 
Актуальные задачи: 
* настраиваемое нижнее меню, чтобы любой пользователь мог поменять назначение функциональных кнопок
* сделать перемещение объектов мышью как в классических приложениях

Присоединяйтесь к разработке этого опенсоурс проекта !
